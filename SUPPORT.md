# Support

Use GitHub issues for reproducible Dockyard defects and feature requests. Include
the Dockyard version, Python version, architecture, deployment method, enabled
profiles, and sanitized reproduction steps. Never include session strings,
tokens, database URLs/passwords, private identifiers, filesystem paths, or raw
logs.

Upstream Ultroid behavior should be reproduced against Dockyard before filing.
Repository topics, description, branch protection, release publication, and
other GitHub metadata are suggestions for Hermes to apply; repository files do
not change those settings.
